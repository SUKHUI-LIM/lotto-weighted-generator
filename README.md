# 🎰 동행복권 통계 기반 5게임 가중치 로또 생성기

과거 동행복권의 회차별 출현 빈도를 통계적으로 분석하여, 많이 나온 번호일수록 높은 가중치를 부여하는 **가중치 랜덤 추첨(Weighted Random Sampling)** 알고리즘 기반 5게임(A~E) 로또 자동 생성기입니다.

---

## 🌟 주요 기능

1. **통계 기반 5게임 가중치 추첨**:
   - $Weight(n) = Count(n) + BaseWeight$ 가중치 공식을 적용하여 최근 당첨 빈도가 높은 번호의 출현 확률 증가
   - 한 번의 클릭으로 중복 없는 6개 숫자로 구성된 로또 5세트(A, B, C, D, E) 일괄 생성
   - 각 게임 내 번호 자동 오름차순 정렬
2. **고정 번호 & 제외 번호 맞춤 필터**:
   - **고정 번호 (최대 5개)**: 지정된 번호는 모든 게임에 100% 필수 포함 후 나머지 슬롯 추첨
   - **제외 번호 (최대 10개)**: 지정된 번호는 추첨 후보 리스트(1~45)에서 완전히 배제
   - 1~45 인터랙티브 볼 패널에서 클릭으로 손쉽게 지정/해제
3. **동행복권 최신 당첨 번호 실시간 연동**:
   - 동행복권 공식 데이터 API를 통한 최신 회차 당첨 번호(보너스 포함), 1등 당첨금, 추첨일 안내
   - 최근 20~50회차 당첨 데이터를 수집하여 1~45번 번호별 출현 빈도수 히트맵 및 Hot/Cold TOP 6 제공
4. **공식 로또볼 색상 & 클립보드 원클릭 전체 복사**:
   - 1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록의 3D 입체 로또볼 구현
   - 카카오톡/메모장에 바로 붙여넣을 수 있는 원클릭 5게임 전체 클립보드 복사 지원

---

## 🛠️ 기술 스택

- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide React
- **Backend**: Node.js, Express, Axios
- **Algorithms**: Weighted Random Sampling without Replacement

## 🚀 로컬 실행 방법

### 1. 패키지 설치
```bash
# 백엔드 의존성 설치
cd server
npm install

# 프론트엔드 의존성 설치
cd ../client
npm install
```

### 2. 실행
```bash
# 백엔드 서버 실행 (포트 4000)
node server/index.js

# 프론트엔드 개발 서버 실행 (포트 5173)
npm --prefix client run dev
```

브라우저에서 `http://localhost:5173`으로 접속합니다.
